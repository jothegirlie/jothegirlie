# 👋 Hey, I'm Johanna

🎓 Business Informatics Student (Distance Learning) @ FSEGA, Cluj-Napoca | Front-End Developer in the making

I got into tech through the practical side first — data entry, spreadsheets, and the kind of repetitive work that makes you start asking "couldn't this be automated?" That curiosity pulled me toward code, and once I got a taste of building interfaces with HTML, CSS, and JavaScript, I was hooked on the process of turning a blank page into something people can actually use.

What motivates me is the mix of logic and creativity that front-end work demands — you need to think like an engineer and design like you care about the person on the other side of the screen. I'm especially interested in where clean code meets business value, which is part of why I'm studying Economic Informatics alongside development.

I enjoy building interfaces that feel simple even when there's a lot happening underneath — dashboards, small web apps, anything with a real user problem behind it. Recently that's meant building a React personal finance app with charts and API integrations, and working through a front-end internship building sites and small games from scratch.

Right now I'm focused on strengthening my React fundamentals, growing my portfolio, and working toward being job-ready as a front-end developer by 2027, when I finish university.
